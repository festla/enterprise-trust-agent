## 2. 选择原则

4. 报告必须能够追溯至公司、年度、报告名称和原始页码。
5. 扫描版、缺页或无法可靠解析的报告需要单独标记。

## 4. 文档质量分级

### A 级：可直接进入 MVP

- PDF 具有完整文本层；
- 页面内容可以正常复制；
- 页码完整；
- 三大财务报表清晰；
- 表格结构大部分可以识别；
- 不存在明显乱码或大面积缺失。

### B 级：可使用，但需要清洗

- 正文文本可以读取；
- 部分表格解析错位；
- 跨页内容需要重新组合；
- 页眉、页脚或目录产生较多噪声；
- 需要人工核验核心财务指标。

### C 级：暂不进入首版 MVP

- 主要内容为扫描图片；
- 存在严重乱码；
- 页面缺失；
- 表格无法可靠读取；
- 需要 OCR 或大量人工修复。

## 5. MVP 纳入规则

- 首版优先使用 A 级文档。
- 必要时允许少量 B 级文档，用于测试解析失败处理。
- C 级文档不进入首版 MVP，只保留为后续 OCR 扩展样本。
- 所有报告必须保留原始文件名、来源、公司、年份和页码。
